# Uber-Trip-Analysis-Dashboard-Power-BI

An end-to-end Business Intelligence dashboard developed in Power BI to analyse Uber trip data and transform raw transportation records into actionable business insights. This project demonstrates the complete analytics workflow—from KPI development and data modelling to interactive dashboard design and business storytelling.
The dashboard enables stakeholders to monitor booking performance, analyse customer travel behaviour, identify peak demand periods, evaluate vehicle utilization, and uncover location-based trends through dynamic visualizations and interactive filtering.

-->Business Objective:
Ride-sharing platforms generate massive amounts of trip data every day. The objective of this project is to convert that data into meaningful insights that help business teams answer questions such as:

1. Which locations generate the highest number of bookings?
2. What are the busiest hours and days for ride demand?
3. Which vehicle categories are most preferred by customers?
4. How do payment methods influence booking patterns?
5. Which pickup and drop-off locations experience the highest traffic?
6. What operational insights can improve fleet utilization and customer experience?

-->Key Performance Indicators (KPIs):
1. 103.7K Total Bookings
2. $1.55M Total Booking Value
3. $14.98 Average Booking Value
4. 349K Miles Total Trip Distance
5. 3 Miles Average Trip Distance
6. 16 Minutes Average Trip Duration
